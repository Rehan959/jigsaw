# Selector 클래스 {#selector-class}

`Selector`는 HTML을 파싱하고 요소를 선택하는 Jigsaw의 핵심 클래스입니다.

`Selector`의 모든 인수, 속성, 메서드를 설명합니다.

`Selector`는 `jigsaw`에서 직접 가져올 수 있습니다:

```python
from jigsaw.parser import Selector
```
