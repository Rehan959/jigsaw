# Класс Selector {#selector-class}

`Selector` является основным классом Jigsaw для разбора HTML и выбора элементов.

Здесь описаны все аргументы, атрибуты и методы `Selector`.

`Selector` можно импортировать прямо из `jigsaw`:

```python
from jigsaw.parser import Selector
```
