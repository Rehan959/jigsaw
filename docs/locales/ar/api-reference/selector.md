# الفئة Selector {#selector-class}

الفئة `Selector` هي أساس تحليل HTML واختيار العناصر في Jigsaw.

هذا مرجع لكل المعاملات والخصائص والطرق في الفئة `Selector`.

يمكنك استيراد الفئة `Selector` كما يلي:

```python
from jigsaw.parser import Selector
```
