# مهارة Jigsaw لوكلاء البرمجة {#jigsaw-agent-skill}

يمنح [خادم MCP](mcp-server.md) مساعد الذكاء الاصطناعي أدوات لاستخراج بيانات المواقع نيابة عنك. أما **مهارة Jigsaw لوكلاء البرمجة** فتعلّم الوكيل استخدام المكتبة نفسها، ليكتب كودًا يطابق الـ API الحالي بدلًا من التخمين اعتمادًا على بيانات تدريب قديمة.

تتبع المهارة مواصفات [AgentSkills](https://agentskills.io/specification)، لذلك يستطيع [Claude Code](https://claude.com/product/claude-code) و[OpenClaw](https://github.com/openclaw/openclaw) وغيرهما من أدوات الوكلاء قراءتها. تجمع إرشادات الجلب والتحليل والزحف وMCP وRAG في مراجع Markdown يحمّلها الوكيل عند الحاجة، مع أمثلة جاهزة للتشغيل. وهكذا يستطيع الإجابة عن معظم أسئلة Jigsaw وكتابة كود صحيح لاستخراج البيانات دون مغادرة المحرر.

توجد المهارة في مجلد agent-skill داخل المستودع باسم `jigsaw-official`، ويتبع إصدارها دائمًا إصدار المكتبة.

نزّل ملف ZIP الخاص بالمهارة مباشرة من المستودع، ثم فكّه داخل مجلد مهارات الوكيل. في Claude Code، هذا المجلد هو `~/.claude/skills/`.

## محتويات المهارة {#whats-inside}

- **`SKILL.md`**: نقطة البداية التي يقرأها الوكيل أولًا. تشرح الإعداد، واختيار أداة الجلب، وقواعد الأمان التي يجب أن يتبعها، مثل تمرير `--ai-targeted` دائمًا إلى أوامر CLI للحماية من حقن التعليمات.
- **`references/`**: نسخ Markdown من صفحات التوثيق، تشمل التحليل والجلب والعناكب وخادم MCP والتكاملات. تُحمّل عند الحاجة فقط، فلا تستهلك مساحة سياق الوكيل قبل أن يحتاج إليها.
- **`examples/`**: سكربتات جاهزة للتشغيل يستطيع الوكيل نسخ الكود منها.
