# Jigsaw Agent Skill

The skill follows the [AgentSkills](https://agentskills.io/specification) specification, so it's readable by [OpenClaw](https://github.com/openclaw/openclaw), [Claude Code](https://claude.com/product/claude-code), and other agentic tools. It gives your coding agent Jigsaw guides and examples for HTTP requests, browser sessions, parsing, crawlers, and AI workflows, so it can use the current API instead of guessing from outdated training data.
